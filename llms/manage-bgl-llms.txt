# Manage BGL (Jade Diabetes)

> Jade Diabetes ("Manage BGL") is a Melbourne, Australia diabetes-management platform whose iOS/Android app tracks blood glucose, calculates insulin doses, and predicts blood sugar hours ahead for Type 1, Type 1.5, Type 2, gestational, and LADA diabetes. It integrates with Dexcom, FreeStyle Libre, NightScout, and 60+ diabetic devices, and exposes a public REST API (v1.0) to read and write diabetes data securely.

## APIs
- [Jade Diabetes REST API](https://jadediabetes.com/api/index.html): Read/write diabetes logs, insulin doses, settings, and BGL predictions over HTTPS with token authentication.
